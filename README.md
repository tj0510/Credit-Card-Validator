
# 💳 Credit Card Validator in Java

This console based program is a **Java-based Credit Card Validator** that analyzes and verifies credit card numbers based on several industry standards like **MII**, **IIN**, and the **Luhn algorithm** (checksum). Perfect for learning about string manipulation, modular arithmetic, and real-world applications of Java.

---

## 🚀 Features

🔹 Validates credit card number length (12 to 19 digits)  
🔹 Identifies the **Major Industry Identifier (MII)**  
🔹 Detects the **Issuer Identification Number (IIN)**  
🔹 Extracts the **account number** from the credit card  
🔹 Applies the **Luhn algorithm** to check if the credit card is valid  

---

## 🧠 Concepts Used

- String operations
- Control structures (`if-else`)
- Luhn Algorithm for checksum validation
- Substring parsing
- User input with `Scanner`
- Modular arithmetic

---

## 🛠️ How to Run

1. Copy the code into a file named `CreditCardValidation.java`
2. Compile the code using:
   ```bash
   javac CreditCardValidation.java
   ```
3. Run the program:
   ```bash
   java CreditCardValidation
   ```

> Make sure you're using a Java environment (JDK 8 or later recommended).
